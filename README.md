# But SI Can ~ INNERG INTEL

A Style A use-case wall in the format of butitcan.com, rebuilt for INNERG INTEL with its own copy, brand and assets.
"SI can't ___, but it can ___." Lines are grouped by the INNERG method: Deprogram, Relearn, Recode, Rebuild.

Static site. No build step. Open `index.html` through any static server, for example `python3 -m http.server`.

- `index.html` ~ hero line rotator (arrows, keyboard, #slug deep links, Share on X, Copy link), method strip, Can't / Can wall with stage filters, Field notes, closer
- `submit.html` ~ line form that opens an X draft tagged @InnerGIntel (interim, no backend)
- `lines.js` ~ the wall content. Every line is a PLACEHOLDER draft until Mr G approves it.
- `assets/seal.jpg` ~ official seal from innerg-pulse

Status: preview only. No custom domain. Not announced. `noindex` is set.
